Every change made to this repository since Tom Perry's last commit,
`d98d01da` *macOS arm64 and modern-toolchain portability fixes* (16 June
2026), which came in with pull request #7. Each line is one commit, under
the first release that included it, newest release first and in the
order the commits were merged within it; the number in brackets is the
pull request that brought it in. Commits that were later reverted are
listed too, and so are their reverts.

OXT-Beyond 0.0.1 and what came before it (the build of LiveCode
Community for Windows, and OpenXTalk Lite's history up to 1.15) are
described in [HISTORY.md](HISTORY.md). What each release adds, in
words, is in the [README](README.md#the-ide) and on the
[Releases page](https://github.com/SethMorrowSoftware/OpenXTalk-Beyond/releases).
