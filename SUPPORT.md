# Getting help with OXT-Beyond

**Start here**

- **Learn inside the IDE.** Home (Help > Welcome to OXT-Beyond) has the
  xTalk Academy, a course in programming for beginners, the how-to
  lessons, the guides and the examples; the Help menu opens each of
  them directly too. The Dictionary (Help > Dictionary) describes every command,
  function, property and message; it is also
  [online](https://sethmorrowsoftware.github.io/OpenXTalk-Beyond/dictionary/).
- **Try it without installing anything** in the
  [web IDE](https://sethmorrowsoftware.github.io/OpenXTalk-Beyond/ide/),
  or open a stack in the
  [Stack Player](https://sethmorrowsoftware.github.io/OpenXTalk-Beyond/player/).
- **Read the README** for downloads, installing on each platform, where
  OXT-Beyond keeps your files and the known limitations:
  [README.md](README.md).

**Ask a question**

Questions about using OXT-Beyond, about xTalk programming, or about
moving a stack from LiveCode, OpenXTalk Lite or HyperCard are welcome
on the [OpenXTalk forums](https://openxtalk.org/forum/), where the
project's release threads are and where most of the community is.

**Report a problem**

- **A bug:** open a
  [bug report](https://github.com/SethMorrowSoftware/OpenXTalk-Beyond/issues/new?template=bug_report.yml).
  Please give the version and build number (the menubar window's title
  and *Preferences > Automatic Updates*), your system, and the steps or
  a small stack that shows it.
- **A build problem** (building from source): use the
  [build problem form](https://github.com/SethMorrowSoftware/OpenXTalk-Beyond/issues/new?template=build_problem.yml).
- **An idea or a feature request:** use the
  [feature request form](https://github.com/SethMorrowSoftware/OpenXTalk-Beyond/issues/new?template=feature_request.yml).
- **A security problem:** please do not open a public issue; see
  [SECURITY.md](SECURITY.md).
- **A problem with an xTalk Suite extension** (SodiumXT, TorrentXT,
  ENetXT, DataChannelXT, OnionXT, NostrXT, Box2DXT, CoinXT): report it
  to the [xTalk Suite](https://github.com/SethMorrowSoftware/xtalk-suite/issues)
  if it happens with the extension alone, or here if it only happens in
  OXT-Beyond.

Please report problems with OXT-Beyond here, not to Terry Little, Tom
Perry or LiveCode Ltd: they do not maintain it.

OXT-Beyond is a volunteer project. There is no paid support and no
guaranteed response time, but every report is read.
