- HyperCard stacks: in a stack whose `hyperTalkCompatible` is true (File > Import Stack sets it), `numToChar` and `charToNum` number the characters by the Mac's character set on every platform, as HyperCard did, where on Windows and Linux they used the platform's: `numToChar(165)` is a bullet there, where it was a yen sign. And 13 is the return, as in HyperCard: `numToChar(13)` ends a line and `charToNum(return)` is 13, where they were a carriage return and 10. `numToChar(10)` is a carriage return in such a stack, and bytes keep their numbers (#262)
- HyperCard stacks: in such a stack, a script can set the script of an object whose handler is running, as in HyperCard, where it stopped with "can't set script while it is executing": the object has the new script at once, for every message after, and the handlers that run go on to their end in the old one. A behavior's script is still refused while its handler runs (#262)
- HyperCard stacks: in such a stack, the id of a card is its abbreviated id, "card id 1234", as in HyperCard, where it was the number: a script that puts the id of this card into a variable, goes to other cards and then goes to that variable comes back to the card, `word 3 of the id of this card` is its number, and `the id of this card is "card id 3058"` is true on that card. Its short id is still the number, and so is the id of a background, a button or a field, as in HyperCard. File > Import Stack's rule T37 now writes `the number of card id (the short id of marked card i)` for HyperCard's `the number of marked card i` (#262)
- HyperCard import: rule T49 puts a field or a button of the card or the background named after `play` in parentheses (`play (card field "sound") tempo card field speed tNotes`), so that the sound is the one the field names, as in HyperCard, where this engine read the "card" as a player's and looked for a field of the background (no such object, in Merz Poetry and Sound Studio). Rule T35 now takes such a field before play's notes (`play (bg fld 1) "c d e"`), and a tempo in one, where it put the field in quotes with the notes; a tempo in another field or an expression (`tempo field 2 c d`) leaves the line as it is (#262)
