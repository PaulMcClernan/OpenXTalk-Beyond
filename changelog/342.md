- Engine: write to process sends the text written, in the encoding the process was opened with. On Linux text and binary writes went out as UTF-16 (so a program reading its input as text, such as an MCP server, got a zero byte after every character), on macOS binary data went out UTF-8 encoded, and a process opened for "UTF-8" text was sent UTF-16 on every platform, all since LiveCode 7. Windows' text and binary writes and macOS's plain text writes (UTF-8) are unchanged (#342)
- Tests: the bytes write to process sends in text, native, UTF-8, UTF-16, UTF-16LE, UTF-16BE and binary mode on Linux and macOS, and that cmd.exe runs what it is sent in text, UTF-8 and binary mode on Windows (#342)
