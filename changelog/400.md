- Standalone Settings, Android card: an "App Bundle" box at the end of the row of architectures, which asks the build for an Android App Bundle (.aab) beside the package (the "android,app bundle" setting, which only a script could set until now). It can be ticked once an architecture is; a stack that never ticks it is built as before (#PR)
- IDE tour: on the Android card, the App Bundle box is right of Android x86_64 and inside the window, enabled with the Android settings, ticked exactly when the stack's setting is true, and a click on it stores the setting and no architecture (#PR)
