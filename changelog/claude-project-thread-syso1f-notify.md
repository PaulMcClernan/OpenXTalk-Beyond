- Android: on Android 13 and newer, an app that declares the notification permission (POST_NOTIFICATIONS in its Android permissions) asks the user to let it post notifications the first time in a run that mobileCreateLocalNotification schedules one, so that the notification shows; an app that does not declare it is never asked, as before, and the notification is scheduled either way (needs the Java layer built from OXT-Beyond's source, which the runtimes asset carries from its next release; run on an Android 13 emulator by the Android builder workflow). androidRequestPermission answers false, instead of stopping the app, when Android answers its request with no result (#PR)
- Android builder check: android_check.py device --allow <permission> waits for Android's dialog asking for a runtime permission, taps Allow and checks that the package holds it; the Java layer's probe declares POST_NOTIFICATIONS and must ask for it on the Android 13 and 16 KB emulators (#PR)
