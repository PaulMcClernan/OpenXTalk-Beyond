- Android: the Java layer is ready for apps that target API 35 and 36. On Android 16, which sends such an app's back button and gesture only to a back callback, the stack still gets backKey (and the busy indicator still closes, as before); on Android 15 and newer, which draw such an app edge to edge, the stack is kept out of the status and navigation bars, the display's cutout and the keyboard (when it resizes the window, as by default), so it has the area it had. Apps that target API 33, as the builder makes them today, are unchanged (needs the Java layer built from OXT-Beyond's source, which the runtimes asset carries from its next release) (#PR)
