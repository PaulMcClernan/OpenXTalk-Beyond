- Web standalones: an HTML5 standalone gets the web engine with the xTalk Suite's sodiumxt, box2dxt, coinxt and datachannelxt libraries only when it includes an extension that uses one of them; any other gets the same engine without them, as every web standalone had before 0.2.7-rc.6.8, and a smaller `.wasm`. The Stack Player keeps the engine with the libraries, and the standalone setting `emscripten,xtalklibraries` set to `always` asks for it in any standalone. The web runtime has the engine without them in `lean/` beside the full one (OpenXTalkPaul, openxtalk.org p=25579)
