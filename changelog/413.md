- Android builder: a stack can be built with OXT-Beyond's own Android engine, built from this tree with a current NDK, instead of LiveCode 9.6.3's, with `set the cRevStandaloneSettings["android,engine"] of stack "<name>" to "beyond"`. The builder then takes the engines, the externals, the Java layer, the manifest and the files beside them from `Runtime/Android/Beyond`, where runtimes that carry this engine keep it, and nothing from 9.6.3's. A stack that names no engine, or "9.6.3", is built as before; asked of runtimes without the Beyond folder, or for any other name, the build stops and says why (#413)
- Android engine: the engine workflow puts the runtime it builds beside the release's (`android_check.py overlay --beyond`) and builds both probes as stacks that ask for it (`ide --android-engine beyond`); the Android check's units run the builder's choice in the release's IDE (#413)
