Lessons Beyond

xTalk is the language HyperCard taught a generation to program in: scripts that read almost like English, in stacks of cards you can see and click. These lessons take you from your first line to libraries, the internet and extensions of your own, one short page at a time. Every example runs, and shows you what it puts.

    Running the examples Each one is a few lines you can change

    1. Open the xTalk Academy in OXT-Beyond: Help > xTalk Academy, in the desktop IDE or the Web IDE. Its playground, on the right, runs xTalk as you type it.
    2. Copy an example with its Copy button and paste it into the playground, over what is there.
    3. Press Run. Each put shows its value on a line of the Output, just as the lesson shows it. Then change the example and run it again.

    An example marked Script is a set of handlers for a button's or a stack's script (open its script with the Script Editor, paste and Apply), and one marked xTalk Builder is an extension's source, for Tools > Extension Builder. Every example on these pages is run by the OXT-Beyond engine, with the Academy's own runner, each time the lessons change, and its Output is checked against what the page shows.
