When a URL is not enough

URL "file:" reads or writes a whole file at once, which is right for almost every file. But a log of millions of lines does not need to be in memory to read its last entry, and a program that writes as it goes should not rewrite the whole file each time. For these, open the file and work on it a piece at a time:

  1. open file it, for read, for write (replacing it), for append (adding to the end) or for update;
  2. read from file or write to file, as often as you need;
  3. close file it, always.

Always close

An open file stays open, and on some systems locked, until you close it or the program quits. the openFiles lists the files still open. Close every file you open, even when something goes wrong: a try with finally (from Handling errors) makes sure of it.

Try it yourself

Write the numbers 1 to 1000 to a file, a line each, with write. Then read the file a line at a time and add up only the lines that are multiples of 7. Put the total, and delete the file.
