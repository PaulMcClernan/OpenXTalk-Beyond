A card of choices

Classic buttons can be radio buttons and check boxes (Buttons and menus), but phones and today's programs have taught people other shapes for choosing: a row of segments, a switch that slides, a swatch of colour. These are widgets (Using extensions), and they are dragged onto a card from the Tools palette like any control. Build a card that styles a line of text:

  1. Make a new stack, or go to an empty card. In Edit mode, scroll the Tools palette down to its widgets and drag a Segmented Control to the top left of the card. Double-click it, name it Size, and in its Property Inspector set the labels of its three segments to Small, Medium and Large.
  2. Drag a Switch Button under it, and name it Bold.
  3. Drag a Color Swatch to the right of the switch, and name it Ink.
  4. Drag a classic Field across the card under them, name it Sample, and type Hello there into it.
create widget "Size" as "com.livecode.widget.segmented"
set the rect of it to 40,40,280,72
set the itemLabels of it to "Small,Medium,Large"
create widget "Bold" as "com.livecode.widget.switchbutton"
set the rect of it to 40,100,100,132
create widget "Ink" as "com.livecode.widget.colorswatch"
set the rect of it to 140,96,180,136
create field "Sample"
set the rect of it to 40,170,440,300
set the text of it to "Hello there"

One of a few: the Segmented Control

A Segmented Control is a row of buttons joined into one, of which one is lit, like radio buttons that take less room. Each segment has a label, the word the reader sees, and a name, for scripts. hilitedItems is the number of the lit segment, and hilitedItemNames its name:

A widget sends its messages once the script that changed it has finished, not at the moment it changes, so the handler has not run yet on the line straight after the set. wait 0 milliseconds with messages lets the message through first. A script that changes a widget and then needs what its handler did must do the same; lines typed into the Message Box one at a time each finish before the next, so there it happens by itself.

Set multipleHilites to true and any number of segments can be lit at once, like check boxes, with hilitedItems a list such as 1,3. Set itemStyle to icons and the segments show itemIcons instead of words, as the Property Inspector's own text alignment does.

A gradient's colours: the Gradient Ramp Editor

A gradient, a colour that fades into others across a graphic (Graphics and images), has stops: at each point along it, a colour. The Gradient Ramp Editor is the strip the Property Inspector shows for a gradient, where the stops can be dragged and recoloured.
