Text into an array: split

split cuts text into the elements of an array. Split by one delimiter and the pieces are numbered from 1:

Split by two delimiters and each piece becomes a key with its value: the first delimiter separates the pairs, the second the key from the value.

That makes settings files, query strings and simple records easy to read.

An array into text: combine

combine is the reverse: it joins the elements into text. With one delimiter you get the values, in the order of their keys when the keys are numbers; with two, the keys and values.

The words by and with mean the same in both commands; use whichever reads better. Remember that combining an array with text keys gives the pairs in no fixed order, so sort the text afterwards when the order matters.

Split as a set

as set makes every piece a key, with true as its value: a quick way to ask "is this one of them?", and to drop duplicates, as Filtering lists showed.

Merging arrays

union adds to an array every key of another that it does not have yet; the keys it already has keep their values. intersect keeps only the keys both arrays have.

Saving an array

An array cannot be written to a file or kept in a field as it is. arrayEncode turns it into binary data that can, and arrayDecode brings it back, nested arrays and all. (For data other programs must read, JSON is the usual choice: see JSON.)
