How many decimals?

Like the itemDelimiter (Chunks), the numberFormat goes back to its default when the handler that set it ends, so setting it in one handler cannot surprise another.

Rounding

round rounds to the nearest whole number, or to as many decimals as you ask. Halves go away from zero. A negative number of places rounds to tens, hundreds and so on. trunc just cuts the decimals off.

Round when you show a value, not while you calculate with it: rounding at every step lets small errors pile up. For money, many programs keep whole cents (or pence) and divide by 100 only to show the amount.

Fill in the blanks: format

format builds text from a template, like printf in C. Each % code in the template is replaced by the next value: %d a whole number, %f a number with decimals, %s text, %x a number in hexadecimal.

A number between % and the letter is a width, which pads the value with spaces; a minus sign pads on the right instead of the left. That is how to line up columns in plain text:

format also turns \n into a new line and \t into a tab, so it is a compact way to write those inside a string.
