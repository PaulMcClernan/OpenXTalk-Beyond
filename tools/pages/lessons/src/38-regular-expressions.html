Patterns for text

A regular expression (a regex) is a small language for describing text: "one or more digits", "a word at the start of the line", "something that looks like an email address". xTalk uses the same regular expressions as Perl, Python and most other languages (PCRE), so what you learn here works almost everywhere.

PatternMatches
catthe letters cat, anywhere
.any one character
[aeiou], [0-9], [^,]one character from a set, a range, or not in a set
\d, \s, \wa digit, a space or tab, a letter or digit or _
*, +, ?after something: any number of it, one or more, none or one
{3}, {2,4}exactly 3 of it, from 2 to 4
^, $the start and the end of the text
(...)a group, which you can capture
a|beither a or b
\., \$a character that means something, taken literally
