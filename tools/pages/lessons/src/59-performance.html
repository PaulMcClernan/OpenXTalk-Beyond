Measure first

Most code is fast enough, and the slow part of a program is rarely where you would guess. So before changing anything for speed, measure: the milliseconds before and after (Timers and waiting), on data as big as the real thing. The examples here time two ways of doing the same work and check that the faster really is faster; each says how the two compared on the computer that checked this page.

Going through lines: repeat for each

This is the biggest one. line i of tText has to count returns from the start of the text every time, so a loop over all the lines with it counts the first lines again and again: twice the lines takes four times as long. repeat for each line walks through the text once:

With 20,000 lines, the check took about 1700 milliseconds by number and 35 with for each. The same goes for item i, word i and char i. When you need the number too, count it yourself inside a for each loop. And put the text into an array with split when you must jump to any line by its number many times (Algorithms).

Work in variables, not in fields

A field is an object on the screen: every change to its text is laid out, and drawn when the screen next updates. Build the text in a variable, and put it into the field once:

The same holds for any property read in a loop: the number of lines of field "Log" or the text of a field asked for on every pass. Read it once into a variable before the loop.

Changing many controls: lock screen

When a handler moves, hides or recolours many controls, the screen may be redrawn after each change. lock screen holds the drawing until the handler ends or unlock screen, so the user sees one finished change, sooner (Animation and games uses it for every frame). lock messages similarly stops openCard, setProp and other messages while a script goes through many cards or objects, for a script that only needs to look at them.

Once code is fast enough, stop. Clear code that is fast enough beats clever code that is a little faster: the next person to read it may be you, in a year.
