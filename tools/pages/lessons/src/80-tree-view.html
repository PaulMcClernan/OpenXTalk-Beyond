A tree of the books

An array of arrays (Arrays) is a tree: each key leads either to a value, a leaf, or to another array, a branch. The Tree View widget shows one as a list whose branches open and close with a click on their triangle, as a file browser shows folders. Build a card with one:

  1. Make a new stack, or go to an empty card. In Edit mode, drag a Tree View from the widgets of the Tools palette to the left of the card, make it tall, and name it Shelf.
  2. Drag a classic Field to the right of it and name it Details.
create widget "Shelf" as "com.livecode.widget.treeview"
set the rect of it to 20,20,280,340
create field "Details"
set the rect of it to 300,20,460,120

The row that is chosen

A click on a row lights it and sends hiliteChanged. The lit row's hilitedElement is its path: the keys from the top of the array down to it, separated by commas, so Science,Cosmos is tShelf["Science"]["Cosmos"]. A double-click on a leaf sends actionDoubleClick with the path, a good place to open the thing the row stands for. If your keys have commas in them, set the pathDelimiter to another character, such as /, and paths use that instead.

A folder as a tree

A folder is a tree too: folders inside folders, with files at the ends. A function that calls itself for each folder inside (Recursion) turns one into an array, each file with its size in bytes, ready for a Tree View:

The files are deleted at the end, and the tree still shows them: it shows its own copy of the array, not the folder. Set its arrayData again to bring it up to date.

Set showValues to false and a Tree View shows only the keys, which makes it a menu of sections, the way a help window lists its chapters. Its dataChanged message tells you when someone has changed an array that is not readOnly.
