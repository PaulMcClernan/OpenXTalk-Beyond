A stack in a phone's browser

A stack built as an HTML5 standalone runs in a web browser (Shipping your program), on a phone's too. The Mobile Web library, made for OXT-Beyond, makes it at home there: it fills the screen with the stack and fills it again when the phone turns, says how much of the stack the on-screen keyboard covers, and turns a finger's movements into messages. On a desktop it does nothing and answers as a desktop would, so the same stack runs in both places. mwIsWeb says which:

One line in openStack starts it. After mwStart, a quick stroke of a finger sends swipe with its direction, two fingers send pinch with how far apart they have moved, and a finger held still sends longPress, each to the control under the finger, as mouseDown is:

A swipe a control does not handle goes on to its card and stack, so these handlers in the stack's script turn the pages wherever the finger is. In the IDE nothing sends them, so try the stack in a phone's browser, or on a desktop browser that pretends to be a phone.

A lasting reference to an object

An object's long id names its stack, and changes when the stack is renamed or saved somewhere else. The Object Repository library gives an object a number that lasts while the program runs: objectRepositoryStore gives one, and objectRepositoryRetrieve gives the object's long id as it is now, or empty once the object is gone. The IDE's palettes use it to keep track of the object they show:

Remove a number you no longer need, so the repository does not grow; objectRepositoryFlush removes every number whose object is gone.

Android

A few libraries do things only an Android phone can. The Toast library shows a toast, the short message that appears near the bottom of the screen and fades by itself; the Android Audio Recorder records from the microphone, and Android Background Audio keeps sound playing when the app is not on screen. The Mac

Two libraries reach parts of macOS that other systems do not have. The Mac Status Menu library puts a menu of your program's own in the row of icons at the right of the Mac's menu bar, and sends macStatusMenuPick when an item is chosen. The macOS Native App Tools library puts a badge on the program's Dock icon, posts a notification, bounces the Dock icon for attention, shows a file in the Finder, and switches the program to dark or light mode:

A standalone carries only the libraries ticked on the Inclusions pane of its settings (Shipping your program), so tick these for the platforms that use them. The Dictionary has every handler of each, with the systems it works on.
