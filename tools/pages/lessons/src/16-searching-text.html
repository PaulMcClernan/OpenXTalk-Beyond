Where is it?

contains tells you whether something is there. offset tells you where: the number of the character it starts at, or 0 when it is not there at all.

Which word, item or line?

The other offsets count in chunks, which is usually what you want for a list: the number of the word, item or line that holds the text.

lineOffset finds the text anywhere in a line, not only a whole line: lineOffset("app", tFruit) is 1. To find an exact line, use is among the lines of, or set the wholeMatches to true first.

How many times?

To count every copy, look again from just after the last one found. offset's third value says how many characters to skip, and the answer is counted from there.

For whole words there is an easier way: loop over the words and compare each one, as in Repeat for each.
