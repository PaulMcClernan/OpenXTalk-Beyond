One piece at a time

Very often you want to do something with every part of a value: each word of a sentence, each line of a list. repeat for each hands you the parts one by one, in a variable you name.

Items and lines

An item is a piece of a list separated by commas; a line is a piece separated by new lines. Both are everywhere in xTalk: the next lesson is about them. Looping over them is how you work through a list:

Why it is the best loop for a list

You could write the same with repeat with i = 1 to the number of lines of tList and line i of tList, but for a long list that is much slower: to find line 5,000, xTalk has to count through the 4,999 before it, every time. repeat for each walks the list once. On a list of thousands of lines the difference is seconds against a blink.

Do not change the value you are looping over inside the loop. Build the result in a second variable instead, as the examples above do.

Arrays: each key, each element

The same loop works on arrays, which you will meet in Arrays: repeat for each key tKey in tArray gives each key, and repeat for each element tValue in tArray each value.
