An app's card

Most apps on a phone look alike for a reason: a bar across the top with the page's title and a button or two, a row of tabs across the bottom to move between pages, and the page itself between them. People know where to look. Three widgets make this layout, and they work on a desktop just as well. Build the card:

  1. Make a new stack, or go to an empty card. In Edit mode, drag a Header Bar from the widgets of the Tools palette to the top of the card, stretch it from edge to edge, and name it Header.
  2. Drag a Navigation Bar to the bottom of the card, stretch it from edge to edge too, and name it Tabs.
  3. Drag a classic Field into the space between them and name it Page.
create widget "Header" as "com.livecode.widget.headerbar"
set the rect of it to 0,0,480,44
create widget "Tabs" as "com.livecode.widget.navbar"
set the rect of it to 0,304,480,360
create field "Page"
set the rect of it to 20,60,460,290

Each bar comes with items to show what it can do: the Header Bar says Title, with a back arrow and a plus, and the Navigation Bar has four tabs with an icon each. They are set in the Property Inspector, or from a script, as properties: a list of names for scripts, of labels for people, and of icons, each a name from the icon library that comes with OXT-Beyond (Icons and SVG). Tabs: the Navigation Bar

One tab of a Navigation Bar is always lit, the page the reader is on. A click on another lights it and sends hiliteChanged, as setting its hilitedItem does; hilitedItemName says which. Tiles

A Tile is a square button with a big icon and a title, the kind of thing a home screen or a settings page shows in a grid. It lights up when the pointer is over it, and sends mouseUp when clicked. Tiles are easy to make by the dozen from a script (Making controls from a script), as here; from the Tools palette each is dragged and set like any widget:

Palette Actions

The IDE's own palettes, such as the Project Browser, have a bar of small icon buttons along their top; it is the Palette Actions widget, and it is in the Tools palette for your own palettes too. It has two sets of items: nav items on the left, of which one is chosen, like tabs, and action items on the right, like buttons.
