Values with names

An array is a variable that holds many values, each filed under a key. You write the key in square brackets after the variable's name. A key can be any text or number; the value stored under it is an element.

An array is not text, so put tPerson on its own shows nothing: ask for its elements, or turn it into text first, as the next lesson shows.

Counting with an array

Arrays shine when you need to count things. Use each thing as a key and add 1 to its element: an element that does not exist yet starts as empty, which add treats as 0.

Looking up a key is fast however big the array is, while finding a line in a long list means reading the list. When you check "have I seen this before?" thousands of times, an array is the tool.
