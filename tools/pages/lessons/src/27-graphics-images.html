Shapes

A graphic is a shape the engine draws: it stays sharp at any size, and you can change it at any time by setting its properties. The Shapes section of the Tools palette has a tile for each kind, from a Rectangle Graphic to a Five Point Star Graphic. Whichever you drag, its style is one of rectangle, roundRect, oval, line, polygon, curve and regular (a regular polygon), and the Inspector's Basic section has the properties of that style.

  1. On a new card, drag four shapes into a row, each about 100 points square: a Round Rectangle Graphic named Rounded, a Regular Polygon Graphic named Hex, an Oval Graphic named Pie, and another Regular Polygon Graphic named Triangle.
  2. In the Property Inspector's Basic section, set the Corner radius of Rounded to 24, the Sides of Hex to 6 and of Triangle to 3, and the Arc of Pie to 270.
  3. Give each a Fill color: violet, teal, gold and orange.
create graphic "Rounded"
set the style of it to "roundRect"
set the roundRadius of it to 24
set the rect of it to 20,120,120,220
set the backgroundColor of it to "#B69CFF"
create graphic "Hex"
set the style of it to "regular"
set the polySides of it to 6
set the rect of it to 135,120,235,220
set the backgroundColor of it to "#5FE0CF"
create graphic "Pie"
set the style of it to "oval"
set the arcAngle of it to 270
set the rect of it to 250,120,350,220
set the backgroundColor of it to "gold"
create graphic "Triangle"
set the style of it to "regular"
set the polySides of it to 3
set the rect of it to 365,120,465,220
set the backgroundColor of it to "#FF7A00"
repeat with i = 1 to 4
   set the opaque of graphic i to true
end repeat

A shape is filled with its backgroundColor when its filled (or opaque: they are the same property) is true, as it is for the palette's shapes, and drawn round with its foregroundColor at its lineSize (Line thickness). Set the lineSize to 0 for a shape with no outline.

Lines, polygons and points

A line or polygon is a list of points, one x,y a line, which the Inspector shows in its Points box. A line can have an arrowhead at either end (Start arrow and End arrow):

  1. On a new card, drag a Line Graphic and name it Arrow.
  2. In the Property Inspector's Basic section, set its Line thickness to 6 and tick End arrow.
create graphic "Arrow"
set the style of it to "line"
set the points of it to "40,40" & return & "140,40"
set the lineSize of it to 6
set the endArrow of it to true

Setting the points moved the arrow and stretched it to run between them. Points are numbers, so a script can work them out. Here a little trigonometry from Math functions places the ten corners of a star, and turns a palette shape into it:

  1. On a new card, drag any shape, a Regular Polygon Graphic say, and name it Star. Give it a pale yellow Fill color.
  2. Drag a Standard Button to a corner and name it Draw.
create graphic "Star"
set the style of it to "regular"
set the opaque of it to true
set the backgroundColor of it to "#FFD479"
set the rect of it to 40,40,140,140
create button "Draw"
set the rect of it to 20,320,102,343

The last point repeats the first, which closes the shape. (For a star by hand, the palette's Five Point Star Graphic is a polygon with its points already in place.)

Gradients and see-through colours

A graphic can be filled with a gradient instead of one colour: in the Inspector, Fill gradient in the Colors section opens a gradient editor. In xTalk, its fillGradient is an array: the type (linear, radial and others), the ramp of colours, each line a position from 0 to 1 followed by red, green and blue, and the points it runs from and to, with via giving its other direction.

  1. On a new card, drag a Rectangle Graphic, name it Sky, and make it cover the whole card. Set its Line thickness to 0.
  2. Drag a Standard Button onto it and name it Sunset.
create graphic "Sky"
set the style of it to "rectangle"
set the opaque of it to true
set the lineSize of it to 0
set the rect of it to 0,0,480,360
create button "Sunset"
set the rect of it to 20,20,102,43

The blendLevel of any control (Blend level, in the Inspector's Colors) makes it see-through: 0 is solid, 100 invisible.

  1. On a new card, drag two Rectangle Graphics, about 140 points square, so that they overlap. Name them Red and Blue, fill them red and blue, and set the Line thickness of each to 0.
create graphic "Red"
set the rect of it to 140,80,280,220
set the backgroundColor of it to "red"
create graphic "Blue"
set the rect of it to 200,140,340,280
set the backgroundColor of it to "blue"
repeat for each item tName in "Red,Blue"
   set the style of graphic tName to "rectangle"
   set the opaque of graphic tName to true
   set the lineSize of graphic tName to 0
end repeat

Images

An image holds pixels: a photo, an icon, a drawing. You usually bring one in with File > Import As Control > Image File, or drag an Image from the palette and choose its file as its Source in the Inspector (the filename property). An image is also something to paint on: with an empty one selected, the palette's Paint Tools draw into it, and a script can paint it too. Its imageData is four bytes for every pixel, row by row, the last three of each being red, green and blue.

  1. On a new card, drag an Image to the middle, name it Pixels, and in the Property Inspector's Position section set its Width and Height to 128.
  2. Drag a Standard Button to a corner and name it Paint.
create image "Pixels"
set the width of it to 128
set the height of it to 128
set the loc of it to 240,180
create button "Paint"
set the rect of it to 20,20,102,43

That is 128 times 128 pixels, at four bytes each. Each pixel's red grows from left to right and its green from top to bottom, so the corners show the four mixes.

export snapshot turns anything on a card into an image or a PNG file, which is how the pictures of the cards in these lessons are made.

Try it yourself

Build a traffic light with the palette: a tall dark grey Round Rectangle Graphic named Box, with three Oval Graphics in it named Lamp 1, Lamp 2 and Lamp 3, red, amber and green from the top. Then add a Standard Button named Next whose script lights one lamp at a time, in turn: the lit lamp has a blendLevel of 0, and the others of 80.

  1. Drag a Round Rectangle Graphic, about 100 points wide and 320 high, name it Box, set its Corner radius to 30 and its Fill color to dark grey.
  2. Drag three Oval Graphics into it, each 70 points across, and name them Lamp 1, Lamp 2 and Lamp 3 from the top. Fill them red, orange and green.
  3. Drag a Standard Button beside it and name it Next.
create graphic "Box"
set the style of it to "roundRect"
set the roundRadius of it to 30
set the rect of it to 190,20,290,340
set the backgroundColor of it to "#333333"
repeat for each item tColour in "red,orange,#22C55E"
   add 1 to tCount
   create graphic ("Lamp" && tCount)
   set the style of it to "oval"
   set the backgroundColor of it to tColour
   set the rect of it to 205, tCount * 100 - 65, 275, tCount * 100 + 5
end repeat
repeat with i = 1 to the number of graphics
   set the opaque of graphic i to true
end repeat
create button "Next"
set the rect of it to 320,20,402,43
Show a solution

At first every lamp has a blendLevel of 0, so the loop finds the last one, and the first click lights Lamp 1. After Lamp 3, mod brings it back round to 1.
