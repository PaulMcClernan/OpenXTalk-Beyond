A field is a container

A field holds text the user can read and, unless you lock it, edit: in Run mode, click into a field and type. In a script a field works like a variable: you put into it, put after it, read it, and use every chunk expression you know on it.

  1. On a new card, drag a Field, make it wide, and name it Notes.
create field "Notes"
set the rect of it to 40,40,340,61

A field holding a number can be used in sums, and changed in place:

  1. On a new card, drag a Field and name it Score. In Run mode, click into it and type 10.
  2. Drag a Standard Button beside it and name it Add 5.
create field "Score"
set the rect of it to 40,40,140,61
put 10 into field "Score"
create button "Add 5"
set the rect of it to 160,40,242,63

The field says 15 after the first click and 20 after the second, and the Message Box shows twice that.

Styling part of the text

Every text property can be set for a chunk of a field, not just the whole field: a word in bold, a line in another colour, a few characters bigger. By hand, select the text in Run mode and choose from the Text menu: Text > Bold, Text > Size, Text > Color. A script names the chunk. A field gives every line the same height unless its fixedLineHeight (the Inspector's Fixed line height, in Text) is false, so turn that off when some lines are bigger than others.

  1. On a new card, drag a Field, make it big, and name it Poem. In the Property Inspector's Text section, turn off Fixed line height.
  2. In Run mode, type three lines into it: The rain in Spain, falls mainly, on the plain.
create field "Poem"
set the rect of it to 40,40,440,200
set the fixedLineHeight of it to false
put "The rain in Spain" & return & "falls mainly" & return & "on the plain" into field "Poem"

Text with its styles: htmlText

the text of a field is its plain characters. the htmlText is the same text with its styles, in a small dialect of HTML. You can read it to save a field's look, and set it to fill a field with styled text in one go.

  1. On a new card, drag a Field, make it wide, name it Styled, and set its Text size to 18.
  2. In Run mode, type Some bold and italic and red. Double-click the word bold and choose Text > Bold, the word italic and choose Text > Italic, and the word red and choose Text > Color > Red.
create field "Styled"
set the rect of it to 40,40,440,100
set the textSize of it to 18
put "Some bold and italic and red" into field "Styled"
set the textStyle of word 2 of field "Styled" to "bold"
set the textStyle of word 4 of field "Styled" to "italic"
set the textColor of word 6 of field "Styled" to "#FF0000"

To copy text with its styles from one field to another, set the htmlText of field "B" to the htmlText of field "A". A plain put field "A" into field "B" copies only the characters.

Label fields

Most text you see in a program that the user cannot change, titles, captions, a score, is a field with its border and background turned off and its text locked. The Tools palette has one ready made: the Label Field.

  1. On a new card, drag a Label Field to the top, make it wide, and name it Title. In the Property Inspector's Text section set its Text size to 30, its Text style to bold and its Text align to left, and in Contents replace Label: with Weekly report.
  2. Drag a second Label Field under it, name it Caption, align it left, set its Text color (in Colors) to a slate grey, and make its contents Everything sold this week, by day.
create field "Title"
set the rect of it to 30,30,450,80
set the textSize of it to 30
set the textStyle of it to "bold"
create field "Caption"
set the rect of it to 30,80,450,110
set the textColor of it to "#64748B"
repeat for each item tField in "Title,Caption"
   set the showBorder of field tField to false
   set the opaque of field tField to false
   set the lockText of field tField to true
   set the dontWrap of field tField to true
   set the textAlign of field tField to "left"
end repeat
put "Weekly report" into field "Title"
put "Everything sold this week, by day" into field "Caption"

Those three properties are all that makes a field a label, and you can set them on any field: Lock text, Show border and Opaque in the Inspector's Basic section. With lockText true the user cannot type into the field, and a click on it sends mouseUp to it like a button's.

Columns with tabs

A tab character moves the text on to the next tab stop. Set a field's tabStops (the Inspector's Tab stops, in its Table section) and lines with tabs between their parts line up as a table. In a script, set the itemDelimiter to tab and each column is an item.

  1. On a new card, drag a Field to the top, make it nearly as wide as the card and about 90 points high, and name it Table. In the Property Inspector's Table section set its Tab stops to 150,300.
  2. Drag a Standard Button under it and name it Fill.
create field "Table"
set the rect of it to 20,20,460,110
set the tabStops of it to 150,300
create button "Fill"
set the rect of it to 20,130,102,153

The backslashes join three lines of the script into one statement, as in Text and numbers. For bigger tables, with columns the user can sort and resize, drag a Data Grid from the palette: its own guide is in Help > Guides.

A list to choose from

A locked field whose listBehavior is true is a list: a click highlights a whole line. The palette's Scrolling List Field is one, with a scroll bar. the hilitedLine says which line is chosen (and setting it chooses one), and the selectedText gives its text.

  1. On a new card, drag a Scrolling List Field, make it about 200 points wide and 90 high, and name it Fruit.
  2. In the Property Inspector's Contents section, replace Choice 1, Choice 2 and Choice 3 with Apple, Pear and Plum, a line each.
create field "Fruit"
set the rect of it to 40,40,240,130
set the lockText of it to true
set the listBehavior of it to true
set the vScrollbar of it to true
put "Apple" & return & "Pear" & return & "Plum" into field "Fruit"

Long text: scrolling

A field with more text than fits needs a scroll bar: the palette's Scrolling Field has one, and on any field you can turn on Vertical scrollbar in the Inspector (the vScrollbar property). Its scroll property is how far down it is scrolled, in points.

  1. On a new card, drag a Scrolling Field, make it about 260 points wide and 160 high, and name it Long.
  2. Drag a Standard Button beside it and name it Fill.
create field "Long"
set the rect of it to 40,40,300,200
set the vScrollbar of it to true
create button "Fill"
set the rect of it to 320,40,402,63

Build long text in a variable and put it into the field once, as here. Putting into a field a line at a time makes it redraw every time, which is much slower when there are thousands of lines.

Try it yourself

Make a list of the days of the week: drag a Scrolling List Field, name it Days, make it tall enough for seven lines, and type the days into its Contents, Monday first. Then, in the Message Box, choose Wednesday, make the weekend red, and put the chosen day.

  1. Drag a Scrolling List Field, about 200 points wide and 140 high, and name it Days.
  2. In its Contents, type the days of the week from Monday to Sunday, a line each.
create field "Days"
set the rect of it to 40,30,240,170
set the lockText of it to true
set the listBehavior of it to true
set the vScrollbar of it to true
put "Monday,Tuesday,Wednesday,Thursday,Friday,Saturday,Sunday" into tDays
replace comma with return in tDays
put tDays into field "Days"
