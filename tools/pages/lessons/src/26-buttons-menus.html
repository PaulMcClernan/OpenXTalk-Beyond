A button of every kind

The Tools palette has a tile for each common kind of button: Standard Button, Rectangle Button, Default Button, Check Box, Radio Button, and the menus, Option Menu, Pulldown Menu, Combo Box, Popup Menu and Tab Panel. They are all the same kind of object, a button, and its style property (Style in the Inspector's Basic section) decides what it is: change the style and a push button becomes a checkbox.

  1. On a new card, drag a Standard Button, a Rectangle Button, a Check Box and a Radio Button into a column, each about 180 points wide.
  2. Name them standard, rectangle, checkbox and radio.
create button "standard"
set the rect of it to 40,20,220,52
create button "rectangle"
set the style of it to "rectangle"
set the rect of it to 40,68,220,100
create button "checkbox"
set the style of it to "checkbox"
set the showBorder of it to false
set the hiliteBorder of it to false
set the opaque of it to false
set the rect of it to 40,116,220,148
create button "radio"
set the style of it to "radioButton"
set the hiliteBorder of it to false
set the opaque of it to false
set the rect of it to 40,164,220,196

A style reads back in lower case, whichever way it was written: radioButton and radiobutton are the same style. The last lines make a button style the palette has no tile for: a rounded one. You could make it by hand too, from a Standard Button, by choosing roundrect as its Style in the Inspector.

Check boxes and hilite

A check box is on or off, and its hilite says which. Clicking it in Run mode turns it on and off by itself (its autoHilite is true), and a script can read or set it.

  1. On a new card, drag two Check Boxes, one under the other, and make each about 280 points wide.
  2. Name them Send me the newsletter and Remember me. The name is what a check box shows beside its box.
create button "Send me the newsletter"
set the rect of it to 40,40,320,70
create button "Remember me"
set the rect of it to 40,80,320,110
repeat with i = 1 to 2
   set the style of button i to "checkbox"
   set the showBorder of button i to false
   set the hiliteBorder of button i to false
   set the opaque of button i to false
end repeat

Radio buttons

Radio buttons offer a choice of one. Put them in a group whose radioBehavior is true (the Inspector's Hilite one radio button at a time, which a new group has already): choosing one then un-chooses the others, and the group's hilitedButtonName says which is on.

  1. On a new card, drag three Radio Buttons into a column, and name them Small, Medium and Large.
  2. Select all three and choose Object > Group Selected. With the group selected, name it Size in the Property Inspector.
create group "Size"
repeat for each item tSize in "Small,Medium,Large"
   add 1 to tCount
   create button tSize in group "Size"
   set the style of it to "radioButton"
   set the hiliteBorder of it to false
   set the opaque of it to false
   set the rect of it to 40, tCount * 36, 200, tCount * 36 + 28
end repeat
set the radioBehavior of group "Size" to true

Buttons that are menus

A button with the style menu shows a menu, and its menuMode says which kind: option (a pop-up list that shows the choice), comboBox (a list you can also type into), pulldown, popup and tabbed. The lines of the button's text are the menu's items: the Inspector calls them Menu Items.

  1. On a new card, drag an Option Menu and name it Colour.
  2. In the Property Inspector's Basic section, replace its Menu Items, Choice 1 to Choice 3, with Red, Green and Blue, a line each.
create button "Colour"
set the style of it to "menu"
set the menuMode of it to "option"
set the rect of it to 40,40,220,70
set the label of it to "Choice 1"
set the text of it to "Red" & return & "Green" & return & "Blue"

the menuHistory is the number of the chosen item, and the button's label shows its text. Until something is chosen the label still says Choice 1, from the palette.

Tabs

The palette's Tab Panel is a button whose menuMode is tabbed: it draws a row of tabs, one for each line of its text. Picking one sends menuPick, and the script shows the controls that belong to that tab (often a group for each) and hides the others.

  1. On a new card, drag a Tab Panel, make it nearly as big as the card, and name it Settings.
  2. Replace its Menu Items, Tab 1 to Tab 3, with General, Display and Advanced.
create button "Settings"
set the style of it to "menu"
set the menuMode of it to "tabbed"
set the showName of it to false
set the text of it to "General" & return & "Display" & return & "Advanced"
set the rect of it to 20,20,460,220

Enabled, disabled and default

A button that cannot be used right now should say so: set its enabled to false (or disable it, or tick Disabled in the Inspector) and it greys out and ignores clicks. The default button of a dialog, the one Return presses, is drawn with a heavier outline on some systems: the palette's Default Button is a Standard Button with default already true.

  1. On a new card, drag two Standard Buttons side by side and name them Save and Close.
create button "Save"
set the rect of it to 40,40,180,76
create button "Close"
set the rect of it to 200,40,340,76

Try it yourself

On a new card, drag an Option Menu named Pizza with the items Margherita, Funghi and Diavola, and a Check Box named Extra cheese. Write a menuPick handler for the menu that puts the order, such as Funghi with extra cheese when the box is ticked. Then tick the box, and pick Funghi.

  1. Drag an Option Menu, about 200 points wide, name it Pizza, and make its Menu Items Margherita, Funghi and Diavola.
  2. Drag a Check Box under it, about 200 points wide, and name it Extra cheese.
create button "Pizza"
set the style of it to "menu"
set the menuMode of it to "option"
set the rect of it to 40,40,240,70
set the label of it to "Choice 1"
set the text of it to "Margherita" & return & "Funghi" & return & "Diavola"
create button "Extra cheese"
set the style of it to "checkbox"
set the showBorder of it to false
set the hiliteBorder of it to false
set the opaque of it to false
set the rect of it to 40,90,240,120
