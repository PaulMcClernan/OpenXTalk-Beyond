The icons

OXT-Beyond comes with a few hundred icons, the ones the Header Bar, the Navigation Bar and the Tile show (Header bars, tabs and tiles). Each is a drawing written as an SVG path, a line of text that tells a pen where to go, so it stays sharp at any size. The Icon SVG library knows them all: iconNames gives their names, a line each, and iconSVGPathFromName gives the path of one:

The names are in lower case, with spaces between words, such as thumbs up or circle arrow up. A name the library does not know gives an empty path. To see them all, put iconNames() in the Message Box, or look through the Icon Picker at the end of this lesson.

The SVG Icon widget

The SVG Icon widget draws one icon, as big as its rectangle. In the Property Inspector its Preset chooses the icon from a menu of them all; from a script it is the iconPresetName. Its colour is its foreColor, as for a field's text; its angle turns it, in degrees clockwise; and flipped turns it upside down. A row of weather icons, made from a script:

An icon keeps its shape when its widget is stretched, as big as fits and in the middle, so a wide SVG Icon draws a cloud no wider than a square one.

A shape of your own

The iconPath is the drawing itself, and it can be one of your own. An SVG path is a list of commands, each a letter and then numbers: M moves the pen to a point without drawing, L draws a straight line to a point, and Z draws back to the start and closes the shape. Points are across and then down, as on a card, so this house starts at the top of its roof:

The numbers only have to be right among themselves: the widget scales the drawing to fit. With maintainAspectRatio false it fills the widget instead, stretched as the widget is; scaledWidth and scaledHeight say how big the drawing came out. SVG paths have curves too, and any drawing program that saves SVG makes them.

To use a shape of your own by name, as the icons that come with OXT-Beyond are used, give it to the library with addIcon, its name, its path, and an empty third value, which matters only to icon fonts:

Icons you add go in a family of their own named custom, apart from the fontawesome family the others are in, and a name can say which family it means, as custom/house does. A widget that takes an icon's name, such as a Tile or a Navigation Bar, can then use it too. The library forgets the icons you add when OXT-Beyond quits, so a stack that uses one adds it each time it opens, in preOpenStack.

A button that lights

An SVG Icon sends mouseUp when it is clicked, so it can be a button. Its highlight draws it in its hiliteColor instead of its foreColor, which suits a button that stays on, such as a heart for liking something. Build a card with one:

  1. Make a new stack, or go to an empty card. In Edit mode, drag an SVG Icon from the widgets of the Tools palette to the card, make it about 100 pixels square, and name it Like.
  2. In the Property Inspector, choose heart empty as its Preset, and a red as its Hilite color.
create widget "Like" as "com.livecode.widget.svgpath"
set the rect of it to 40,40,140,140
set the iconPresetName of it to "heart empty"
set the hiliteColor of it to "214,40,57"

The Icon Picker

The Icon Picker shows the icons in a grid to scroll through, and lets people choose one with a click, which sets its selectedIcon and sends mouseUp. A second click on the chosen icon unchooses it, and leaves selectedIcon empty. Its filterString shows only the icons whose names contain it. Build a card with one:

  1. Make a new stack, or go to an empty card. In Edit mode, drag an Icon Picker from the widgets of the Tools palette to the left of the card, make it about 300 pixels square, and name it Picker.
  2. Drag an SVG Icon to the right of it, make it about 120 pixels square, and name it Preview.
create widget "Picker" as "com.livecode.widget.iconpicker"
set the rect of it to 20,20,320,340
create widget "Preview" as "com.livecode.widget.svgpath"
set the rect of it to 340,40,460,160

Put this in the Icon Picker's script, so the Preview shows each icon that is chosen:

Setting selectedIcon from a script sends nothing, so the example sends the mouseUp a click would. An Icon Picker can also appear only when it is wanted, as a menu does: popup widget "com.livecode.widget.iconpicker" at the mouseLoc shows one under the pointer, waits for a choice, and puts the icon's name in the result, or empty when the choice was abandoned.
