Calling a function

A function takes some values, works something out and gives back the answer. xTalk has hundreds built in. You call one with its name and its values in brackets, separated by commas. A function's answer can go wherever a value can: into put, a variable, a sum, or another function.

round rounds a half away from zero, as you learnt at school; its second value says how many decimal places to keep. trunc just drops the decimals, and abs drops the minus sign.

A function with one value can also be written the HyperCard way, with the and of: the sqrt of 81 is the same as sqrt(81).

Biggest, smallest, total, average

These take any number of values, or one value that is a list separated by commas, which is handy when the numbers are in a variable.

Roots, powers and pi

Angles

The trigonometry functions work in radians, where a whole turn is 2 * pi. To use degrees, multiply by pi / 180 on the way in, and by 180 / pi on the way out. They are what you need to move something in a circle, or point it at the mouse.
