Two ways to join

Joining strings together is called concatenation. xTalk has two operators for it: & joins two values exactly as they are, and && joins them with a space between.

Numbers join just like text, and a sum is worked out before it is joined. You can chain as many pieces as you like on one line.

Names for characters you cannot see

Some characters are hard to type inside quotes. xTalk gives them names, called constants, which you join like any other value:

ConstantIs
spaceone space (&& is a shortcut for & space &)
taba tab character, for columns
return (or cr)a new line
comma, colon, slash, : /
quotea double quote, "
emptynothing at all, the same as ""

Building a string a piece at a time

Long text is often built in a variable, a piece at a time, with put ... after (and put ... before for the front). Variables come in the next lesson, but the idea is simple: tLine is a named place to keep the string while it grows.

Numbers inside text

When you join a number to text, its digits become part of the string. Be careful with sums: brackets make sure the sum happens before the join.

The last line shows why brackets help: + is worked out before &, so xTalk adds 2 and 3 first and then joins the 1 in front, giving the string 15.

&& always adds exactly one space, even if a string already ends with one. "Hello " && "you" gives two spaces.
