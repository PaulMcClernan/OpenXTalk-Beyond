A stack of cards

A stack shows one card at a time. Each card is a screen of its own: a page of a book, a step of a quiz, a record in an address list. Object > New Card adds a card after the one you are on and goes to it, Object > Card Inspector names it, and the View menu moves between them: Go First, Go Prev, Go Next and Go Last. In a script, create card adds one and go moves.

  1. Start a new stack. In the Card Inspector (Object > Card Inspector), name its card Home.
  2. Choose Object > New Card and name the new card Help; then again, and name the third card About. You are left on About.
set the name of this card to "Home"
create card "Help"
create card "About"

go next card on the last card goes round to the first, and go previous card on the first to the last, so a stack is a ring of cards. You can also go first card, go to card 2, or go back to the card you were on before.

Which card is this?

  1. Start a new stack with three cards (Object > New Card twice), and name them Page 1, Page 2 and Page 3 in the Card Inspector.
set the name of this card to "Page 1"
create card "Page 2"
create card "Page 3"

the number of this card is its place in the stack, and the cardNames lists every card's name, a line each. The Project Browser (Tools > Project Browser) shows the same list, and goes to a card when you double-click it.

Each card gets ready: openCard

Going to a card sends it openCard, and leaving it sends closeCard. A handler in a card's script hears them only for that card; one in the stack's script hears them for every card that does not handle them itself. On a stack of three cards, put this in the stack's script (Object > Stack Script):

  1. Start a new stack with three cards (Object > New Card twice), and go back to the first (View > Go First).
create card
create card
go to card 1

Controls on every card: backgrounds

Many stacks want the same controls on every card: a title, Next and Back buttons, a field for each part of a record. Put them in a group and tick Behave like a background in the group's Inspector (its backgroundBehavior): every card you make after it gets the same group. It is one group, placed on many cards.

  1. Start a new stack. Drag a Field, make it fill most of the card, name it Text, and set its Text size to 24. Drag a Standard Button to the bottom right corner and name it Next.
  2. Select both and choose Object > Group Selected. Name the group Page, and in its Basic section tick Behave like a background.
  3. In Run mode, type First page into the field. Choose Object > New Card: the new card has the field and the button too. Type Second page into the field there.
create field "Text"
set the rect of it to 20,20,460,280
set the textSize of it to 24
create button "Next"
set the rect of it to 340,300,460,340
group field "Text" and button "Next"
set the name of it to "Page"
set the backgroundBehavior of group "Page" to true
put "First page" into field "Text"
create card
put "Second page" into field "Text"

Three controls: the field, the button and the group that holds them. The field is shared, but each card keeps its own text in it: that is what a field's sharedText (Share text), false unless you change it, means. So a stack of cards with a background is a little database, one record a card, the way HyperCard's address books worked.

In HyperCard a card's background was a layer of its own. OXT-Beyond, like LiveCode, makes a HyperCard background into a group with backgroundBehavior true when it imports a stack, and the scripts that said background field "Name" still work.

Tick Share text for a field that should show the same text on every card, like a heading:

  1. Start a new stack. Drag a Field, name it Heading, and tick Share text in its Basic section.
  2. Group it (Object > Group Selected) and tick the group's Behave like a background.
  3. Type My recipes into the field in Run mode, then add two cards with Object > New Card.
create field "Heading"
set the sharedText of field "Heading" to true
group field "Heading"
set the backgroundBehavior of it to true
put "My recipes" into field "Heading"
create card
create card

The button is on every card, so the same script works from each, and the second click goes round from the last card to the first. visual effect animates the change of card; the effects include dissolve, wipe, push, scroll and reveal, with a direction where it makes sense:

A Back button is the same with push right and go previous card, and a Home button just says go first card. Each goes in its own button's script: one script can have only one handler of each name.

Deleting cards

Object > Delete Card removes the card you are on, and delete card does the same from a script, with the controls that are only on it. A stack always keeps at least one card.

  1. Start a new stack and name its card Start. Add a card with Object > New Card and name it Scratch, then go back to the first (View > Go First).
set the name of this card to "Start"
create card "Scratch"
go to card "Start"

Try it yourself

Build a three-card flash-card stack: a background group with a field Word in large, centred type and a button Next, and the words bonjour, merci and au revoir typed on the three cards. Give Next a script that goes to the next card and puts its word. Then, from the first card, click Next three times.

  1. Start a new stack. Drag a Field to the middle, name it Word, set its Text size to 32 and its Text align to center. Drag a Standard Button under it and name it Next.
  2. Group the two and tick Behave like a background. Type bonjour into the field.
  3. Add a card with Object > New Card and type merci; add another and type au revoir. Go back to the first card.
create field "Word"
set the rect of it to 90,140,390,220
set the textSize of it to 32
set the textAlign of it to "center"
create button "Next"
set the rect of it to 199,240,281,263
group field "Word" and button "Next"
set the backgroundBehavior of it to true
put "bonjour" into field "Word"
create card
put "merci" into field "Word"
create card
put "au revoir" into field "Word"
go first card
