One kind of value

Many languages make you say whether a value is text or a number, and refuse to mix them. xTalk does not: every value can be read as text, and a value that looks like a number can be used as one. It works out what you mean from what you do with it.

+ wants numbers, so the text "5" is read as one. & wants text, so 10 and 5 are joined into 105. And empty, in a sum, counts as 0.

True and false

A comparison gives true or false, which are just the words "true" and "false". xTalk calls them booleans. You can keep one in a variable and use it later in an if.

Only the word true is true. In some languages 1 or "yes" count as true too; in xTalk if 1 then does nothing. Compare with what you mean: if tCount is 1 then.

Numbers compare as numbers

When both sides look like numbers, xTalk compares them as numbers, even when they are written differently. Otherwise it compares them as text, in alphabetical order, and without minding capital letters.
