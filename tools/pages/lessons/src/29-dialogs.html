Saying something: answer

answer shows a small dialog with a message and an OK button, and waits until the user clicks it. You met it in the very first lesson. Add with and a list of buttons, separated by or, and the button the user clicks comes back in it:

The last button is the default, the one the Return key presses. Put the safest choice last when a mistake would be costly.

Dialogs wait for a person, so the examples in this lesson are scripts to try in a button, and are only checked to compile. They all work in the playground too: press Run and answer the dialogs.

Kinds of answer

A word after answer gives the dialog an icon that says what kind of message it is: information, question, warning or error. titled sets the dialog's title.

Asking a question: ask

ask shows a question with a box to type in. What the user typed comes back in it. If they click Cancel, it is empty and the result is Cancel, so always check before you use the answer:

The text after with is already in the box when the dialog opens. ask password is the same, but shows dots in place of what is typed.

Choosing a file or a folder

answer file shows the system's dialog for opening a file, and ask file the one for saving. Each puts the chosen file's full path in it, or sets the result to Cancel. answer folder chooses a folder.

The lesson Reading and writing files explains URL "file:".

More dialogs

  • answer color shows a colour picker, and puts the colour chosen in it.
  • answer printer shows the printer settings.
  • A stack of your own can be a dialog too: modal stack "Options" opens it and waits until it closes, and it can hand back a value in the dialogData.

Dialogs interrupt. Use them for questions that need an answer before anything else can happen. For news the user can read when they like, a line in a status field is kinder.

Try it yourself

Write a button script that asks for two numbers, one after the other, and answers their sum. If either dialog is cancelled, stop quietly; if either answer is not a number, say so and stop.
