JSON in one look

JSON (JavaScript Object Notation) is plain text for structured data, and almost every web service sends and takes it. Its pieces map onto xTalk's naturally:

The two functions that do the work, JSONImport and JSONExport, come in the JSON library that OXT-Beyond loads as it starts.

Writing JSON: JSONExport

JSONExport turns an xTalk value into JSON text, escaping quotes and line breaks in strings for you:

The last two lines show a difference that matters to many services. A value that xTalk holds as a number is written as a JSON number; one it holds as text is written as a string, even when the text is digits. A value typed in a script, or read from a field or a file, is text; arithmetic (here + 0) makes it a number.

The keys of an array have no order (Arrays), so JSONExport may write an object's members in any order. JSON does not care about the order of an object's members, and any program that reads JSON properly does not either.

Writing a JSON list
