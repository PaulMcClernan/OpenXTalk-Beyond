Every object has properties

A property is one fact about an object: its name, its size, its colour, the text on it, whether it can be seen. The Property Inspector shows the properties of what you have selected, with friendly labels, and lets you change them by hand. xTalk reaches the same properties by their own names: you read one with the and change one with set.

  1. Start a new stack (File > New Stack > Default Size), or add a card to yours (Object > New Card).
  2. In Edit mode, drag a Standard Button to the top left of the card, and in the Property Inspector name it Big.
  3. Drag its bottom right corner until it is about 200 points wide and 60 high. The Property Inspector's Position section shows its Width and Height as you drag.
create button "Big"
set the rect of it to 40,40,240,100

The Inspector and xTalk are two doors into the same room: what you set in one, the other sees. Hold the pointer over a label in the Inspector to see the property's xTalk name.

A button's label is the text it shows; its name is what scripts call it. Keeping them apart lets you change the words on a button, or translate them, without breaking a single script.

Size and place

When you drag a control or its corners, you are changing several properties at once, and they all stay in step: change one and the others follow.

  • rect: left, top, right, bottom
  • loc: the point at its centre (Location in the Inspector)
  • width and height
  • left, top, right, bottom, and the corners topLeft, bottomRight and so on
  1. Drag a Rectangle Graphic onto a card and name it Box.
  2. In the Property Inspector's Position section, set its Width to 200 and its Height to 100.
  3. In its Colors section, set the Fill color to a light teal, and in Basic, set the Line thickness to 4.
create graphic "Box"
set the style of it to "rectangle"
set the opaque of it to true
set the backgroundColor of it to "#5FE0CF"
set the lineSize of it to 4
set the rect of it to 60,60,260,160

Moving the centre to 200,150 moved the whole rectangle and kept its size. (A graphic draws its line in its foregroundColor; buttons and fields use it for their text.) Colours

A colour can be a name ("orange", "navy", "darkred"), a web-style hex code ("#5FE0CF") or three numbers from 0 to 255 for red, green and blue. backgroundColor fills a control (the Inspector's Fill color), textColor colours its text, and borderColor the edge of a button or field. In the Inspector, clicking a colour opens a colour chooser.

  1. Drag three Rectangle Graphics onto a card, in a row, each about 100 points square.
  2. Name them Square 1, Square 2 and Square 3, from left to right.
repeat with i = 1 to 3
   create graphic ("Square" && i)
   set the style of it to "rectangle"
   set the opaque of it to true
   set the rect of it to i * 120 - 80, 120, i * 120 + 20, 220
end repeat

A colour reads back the way it was set: three numbers stay three numbers, and a hex code stays a hex code.

Text properties

Fields and buttons share a set of text properties, in the Inspector's Text section: textFont, textSize, textStyle (plain, bold, italic, underline and more, joined with commas) and textAlign (left, center or right), and in Colors, textColor.

  1. Drag a Field to the top of a card, name it Greeting, and make it nearly as wide as the card and about 60 points high.
create field "Greeting"
set the rect of it to 20,40,380,100

Showing and hiding

A control's visible property says whether it shows (the Visible box in the Inspector's Basic section). hide and show are short ways to set it. A hidden control is still there, with all its properties and its script: it is only out of sight.

  1. Drag two Oval Graphics onto a card, side by side. Name the left one Shown and the right one Hidden, and set the Fill color of both to royal blue.
  2. Drag a Standard Button under them and name it Peek.
create graphic "Shown"
create graphic "Hidden"
repeat for each item tName in "Shown,Hidden"
   set the style of graphic tName to "oval"
   set the opaque of graphic tName to true
   set the backgroundColor of graphic tName to "royalblue"
end repeat
set the rect of graphic "Shown" to 60,60,180,180
set the rect of graphic "Hidden" to 240,60,360,180
create button "Peek"
set the rect of it to 159,220,241,243

The hidden circle still counts. Now give the button Peek a script that turns the circle on and off: not turns true into false and back.

A hidden control is easy to lose in Edit mode. The Project Browser (Tools > Project Browser) lists every control of every card, hidden or not, and selects the one you click.

Inherited properties

Text properties that a control leaves empty come from the object that holds it: its card, then its stack. Set the textSize of a card and every field on it follows, unless a field sets its own. the effective asks for the value the control really uses:

  1. Drag two Fields onto a card and name them A and B.
create field "A"
set the rect of it to 40,40,140,61
create field "B"
set the rect of it to 40,80,140,101

This is how a whole stack gets one font: set its textFont once, on the stack (in the Stack Inspector, Object > Stack Inspector), and leave the controls' own empty. A stack made with File > New Stack starts with a textSize of 16, which its controls use until you set one of theirs.
