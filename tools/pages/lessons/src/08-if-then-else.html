If this, then that

Programs become interesting when they decide. if checks a condition, and runs the lines up to end if only when it is true.

The condition is anything that is true or false: a comparison, or a variable holding one. The lines inside are indented by three spaces so that you can see at a glance what belongs to the if; the Script Editor does that for you.

Otherwise: else

else gives the lines to run when the condition is false. One of the two always runs, never both.

Several choices: else if

To choose between more than two things, chain else if. xTalk checks each condition in turn, from the top, and runs the first one that is true; the final else catches everything else.

Order matters. 64 is also >= 40, but the >= 60 test comes first and wins. Put the strictest test at the top.

Short forms

When there is only one thing to do, the whole if can go on one line, with no end if. An else then goes at the start of the next line.

Keep a one-line if with put and else on two lines, as above. On one line, xTalk reads the else as part of the put and the script will not compile. When in doubt, use the full form with end if: it is never wrong.

Decisions inside decisions

An if can hold another if. The indentation shows which else belongs to which.
