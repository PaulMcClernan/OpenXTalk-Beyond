Installing a package In any IDE built on LiveCode Community 9

  1. Download the extension's .lce file, and its helpers, Kit or script layer if you want them.
  2. Open Tools > Extension Manager, click + and choose the file.
  3. Install a library before what is built on it: TorrentXT before its Helpers, CoinXT before its script layer, OnionXT before its web server. A plugin appears in Development > Plugins.

The native libraries carry their builds for Windows, macOS 10.15 or later and Linux (64-bit and 32-bit x86, and 64-bit ARM), and the IDE picks the right one. In OXT-Beyond a package you install is used in place of the built-in copy; uninstall it in the Extension Manager to go back.
