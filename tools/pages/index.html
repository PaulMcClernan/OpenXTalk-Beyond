OXT-Beyond on the Web

Build and play xTalk stacks in your browser, with nothing to download or install.

Web IDE

@IDE_VERSION@

The OXT-Beyond IDE itself: make stacks with the Tools palette, the Property Inspector and the Script Editor, try the lessons and the xTalk Academy, and read the Dictionary. Your stacks are kept in this browser between visits, and File > Download Stack saves a copy. The first visit downloads about 60 MB.

Open the Web IDE

Stack Player

@PLAYER_VERSION@

Open any stack from your computer, or a .zip with a stack and its files, and run it in the page. It comes with whole stacks to play, small samples and games, and a plain account of what works on the web.

For contributors: how the engine, the IDE's stacks and libraries, the extensions and the build fit together, the order the IDE searches its scripts in, what each change could break, and the project's history. Rebuilt from the source each time this site is.
